# 跨平台电商运营知识库

用于沉淀各平台的规则、运营方法、实验、复盘与外部流量经验。目标是可持续的真实贡献利润，而不是盲目堆商品、网站或流量。

## 统一原则

- **平台隔离**：平台经验只写入各自目录，公共方法才进入共享区。
- **规则先行**：先核验官方规则、资质、费用、履约和宣传限制，再执行。
- **合规优化**：只做公开规则允许的灰度实验，不绕过审核、风控或权限，不做虚假交易、侵权或流量作弊。
- **小步验证**：先单均经济模型和真实履约，再单变量、小批量测试，最后放大。
- **数据安全**：不保存密钥、个人信息、精确成本底线、供应商标价或未公开财务数据。

完整约束见[运营工作规则](.github/instructions/operations.instructions.md)。

## 新增平台

复制 `platforms/_template`，先补齐官方规则、账户模式、履约、费用和合规边界。可以复用验证方法，但不得直接套用其他平台的费率、广告定义或运营结论。

## 记忆格式

事实 → 已执行及原因 → 回读与费用 → 运营判断 → 推荐/备选方案 → 待验证假设 → 用户需决策事项 → 下一步与停止条件。

失败、回滚和未验证假设也必须记录。示例一律使用假设数据并明确标注。
